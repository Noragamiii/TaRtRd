# Tarot Smith-Waite

App xem tarot cho bộ Smith-Waite Centennial: bốc bài thật rồi nhập lá, hoặc bốc trong app; giải nghĩa 78 lá theo vị trí, chiều xuôi/ngược và chủ đề; dự báo ngày, tuần, tháng, 12 tháng; so sánh lựa chọn A/B/C; nhật ký đồng bộ giữa các máy.

Chạy offline sau lần mở đầu (service worker). Xem `HUONG-DAN.txt` để cài lên iPhone/Mac và bật đồng bộ.

Ảnh lá bài và ảnh biểu tượng lấy từ bộ thẻ Anki "Tarot Meanings" của chủ repo.
